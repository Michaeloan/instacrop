## 📷 照片扫好了，接下来呢？

一张张拍立得攒起来，旅行、聚会、生日、某个普通却很开心的下午……放在盒子里很好看，想存在手机里、做相册、发给朋友时，却多了一道工序。

把几张相纸一起扫出来很方便。然后，你可能就得重复这些操作：

> 打开大图 → 找到一张照片 → 框选 → 扶正 → 切掉多余背景 → 保存 → 再来一次。

照片越多，这件事越容易从「整理回忆」变成「整理到没脾气」。

**InstaCrop 就是为这一步做的小工具。** 导入一整页扫描图，它会尝试找到每张相纸，分别裁出来、拉正。你检查一下结果，需要调整的地方动动四角，最后一起导出。

它适合想把实体照片存成电子版的人，也适合已经扫描了一堆照片、一直没空挨张裁剪的人。

## 🏞 把林间的一小片蓝色，认真保存下来

金绿的树叶、横过画面的枝条、清透的蓝色水面，是这张风景相纸最喜欢的几个细节。

## ✨ 你能用它做什么？

### 01 / 一页里有好几张，帮你分开整理

不需要每次只放一张相纸，也不要求一整页全是相同尺寸。竖的、横的、大的、小的，可以在同一页里识别。

扫描图中的照片会分别进入列表，附上来源文件与页码。再导入下一页时，照片会追加到当前批次，之前的调整会保留。

1.0.3 将素材整理和裁剪分为三个页面：「图片库」管理原始来源，「扫描裁剪」处理整页扫描图，「照片调整」处理已经分开的普通照片。各页面分别保留来源、搜索和检查条件。

### 02 / 有点歪，可以拉正；不太准，可以自己改

自动识别负责先做一遍，需要精细处理时再点「调整」。

- **拖动四个角**：让裁剪框贴住真正的相纸边缘。
- **局部放大镜**：检查细小的白边、阴影和角点。
- **边缘吸附**：尝试贴近附近的边缘；需要自己控制时可以关闭。
- **方向键微调**：把角点一点点挪到合适的位置。
- **旋转与透视调整**：处理倒着放、轻微倾斜或梯形变形的照片。
- **四边分别收边**：只想多裁掉右边的一条扫描阴影，不必让另外三边一起变窄。

这些调整从原扫描图计算。界面预览缩小了，也不会把预览小图当成最终导出文件。

### 03 / 留白边，还是只要画面？都给你准备好

| 成图样式 | 看起来是什么样 | 什么时候想用它 |
| --- | --- | --- |
| **带白边** | 保留相纸外框与下面较宽的留白 | 喜欢拍立得的完整样子，想保留签名、日期与纸张感 |
| **照片画面** | 提取相纸里面的影像区域 | 整理电子相册、打印排版，或只想分享照片内容 |
| **背景成图** | 把相纸居中放进背景画布 | 想保留实体照片的感觉，又希望分享时有一点留白 |

扫描裁剪和照片调整页可以切换三种预览。导出结果会按样式整理，方便你选用。

> 小提醒：导出照片画面前，先检查内部四角是否贴住影像边缘。边界不清楚时，可以手动补框。

### 04 / 一批照片，一起处理

按来源筛选、搜索文件名或页码，选中想保留的照片，再一起导出。

导出和批量参数只作用于当前筛选结果中的选中照片；隐藏在其他来源或分类中的照片不会一起处理。图片库可批量移除选中的来源，操作前会说明相关裁剪成图一起移除，外部原文件保留。

相同的收边、背景比例与部分调整参数可以批量应用；各张照片的四角仍然分别保留。批量操作支持撤销，不需要为了改一个统一参数重新导入整批照片。

### 05 / 今天整理一半，下次接着来

可以保存项目，把原素材和调整记录一起留下。下次打开项目，继续检查剩下的照片。

软件也会在本机工作区保留当前批次。重要的整理结果，建议主动保存一个项目文件作为备份。

## 🌷 第一次使用，跟着这 5 步走

### ① 下载，然后解压

打开 **[最新版下载页](https://github.com/Michaeloan/instacrop/releases/latest)**，在 **Assets（下载附件）** 中找到 `InstaCrop-Windows-1.0.3.zip`。

下载后先解压，再双击文件夹里的 **`InstaCrop.exe`**。

**不要只把 EXE 单独拿出来。** 旁边的 `_internal` 文件夹也是程序的一部分，要一起保留。

| 使用条件 | 说明 |
| --- | --- |
| 电脑系统 | Windows 10 / 11，64 位 |
| 窗口组件 | Microsoft Edge WebView2 Runtime |
| Python | 下载便携版后，不需要自己安装 |
| 账号 | 使用裁剪功能不需要登录账号 |

如果启动时提示缺少 WebView2，可从 [微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/#download-section) 安装 Runtime，再重新打开软件。

### ② 导入扫描图

先进入 **「扫描裁剪」**，点击 **「导入扫描图」**，选择一张或多张扫描文件。也可以点击该页的 **「导入文件夹」**。

- 一张图里有多张相纸：使用「导入扫描图」，让软件寻找各张相纸。
- 文件本来就是一张独立照片：进入「照片调整」，使用「导入照片」，直接加入，方便后续调整和整理。
- 多页 TIFF：扫描导入会把里面的各页加入批次。

文件夹导入只读取当前文件夹这一层。如果照片放在子文件夹里，请分别导入。

拖放按当前页面确定导入类型：扫描裁剪页执行扫描识别，照片调整页直接加入照片。图片库会提示先进入对应页面，避免沿用上次导入类型。

### ③ 先看看「待检查」

自动处理完成后，先看照片是否齐全、方向是否正确，再看边缘是否裁到了合适的位置。

勾选 **「只看待检查」**，可以集中处理不确定的结果。相纸少了一张时，使用更多菜单中的 **「手动补一张照片」**，沿着四角补出外框。

### ④ 想改哪里，就调整哪里

点击照片卡片上的 **「调整」**。先处理裁剪、朝向和收边，再按需要查看污点或颜色。

满意后点「完成」保存本次调整；如果想放弃刚才的改动，点「取消本次调整」。

### ⑤ 选好照片，一起导出

勾选要导出的照片，点击 **「导出照片」**，选择保存文件夹，即可直接得到 PNG 照片，无需解压。需要传输压缩包时，从更多菜单选择 **「导出 ZIP 压缩包」**。

导出后只有「带白边」「照片画面」「背景成图」三个文件夹，照片直接放在对应类别中。文件名采用「来源_第001页_照片001_带白边.png」格式，另外两类分别以「_照片画面.png」「_背景成图.png」结尾，便于对应同一张照片；不会附带原始副本、蒙版、预览图或导出清单。重复导出使用新名称或新目录，避免覆盖已有结果。

**原扫描文件不会被改写。** 你可以先试一遍，再慢慢调整。

## 🍃 想让自动裁剪更顺利，可以这样扫描

识别的起点是扫描图。前面多留一点余地，后面往往能少调几个角。

| 扫描时的小习惯 | 为什么有帮助 |
| --- | --- |
| 相纸之间留一点空隙 | 边缘分开，比较容易识别成不同照片 |
| 尽量不要叠放相纸 | 被挡住的边和角无法从扫描图中找回来 |
| 让整张相纸都在扫描范围里 | 缺了一个角，通常就需要人工补框 |
| 选择和相纸边缘有反差的背景 | 白边贴在几乎一样白的背景上，边界会更难判断 |
| 保留较清楚的扫描原图 | 角点、细节和最终导出都依赖原图质量 |

不用为了摆得一丝不差反复挪照片。轻微的旋转可以后续校正；比「绝对整齐」更重要的是 **边缘看得见、照片不重叠**。

## 🧽 关于白边、灰尘和颜色

裁剪之外，保留了少量配套的整理功能：轻清理白边、污点处理、保护画笔与颜色调整。

**内部画面的自动修复与调色默认关闭。** 想保留照片原本的颜色，可以先保持默认，只处理裁剪。白边轻清理可在更多菜单中开关。

照片里的高光、文字、树叶纹理和小颗粒，偶尔也会看起来像污点。使用除尘时请检查标记区域；可以用保护画笔把不想处理的细节排除。

如果相纸上写着日期、名字或一句话，导出前也记得确认这些笔迹完整保留。

## 🔒 照片留在哪里？

**识别、裁剪、调整和导出都在你的电脑上完成。** 打开软件即可整理静态照片，使用裁剪功能无需登录账号。

原始外部文件不会改写。导入的素材与编辑记录会保存在本机工作区，方便恢复整理进度。

保存的项目文件和导出的 ZIP 会包含照片内容。如果准备分享文件，先确认里面放了哪些照片。本文使用的风景样例已随介绍公开展示；你自己导入的其他照片保存在本机工作区。

## 💬 你可能想问

<details>
<summary><strong>只能处理 Instax Mini 吗？方形、宽幅或者其他相纸呢？</strong></summary>

不是只按一种固定相纸尺寸裁剪。它根据扫描图里的边缘寻找矩形相纸，支持同一页里的混合尺寸，也可处理其他矩形照片。不同纸张、背景和扫描质量会影响识别结果，仍然建议检查。

</details>

<details>
<summary><strong>扫描文件支持哪些格式？</strong></summary>

扫描导入支持 JPG / JPEG、PNG、TIFF、BMP、WebP；TIFF 可以包含多页。直接导入独立照片时，额外支持 HEIC / HEIF。

单页图像上限为 2 亿像素。大图较多时处理会更慢，建议先用少量文件熟悉流程。

</details>

<details>
<summary><strong>没有识别出来，或者裁得不够准，怎么办？</strong></summary>

可以手动补一张照片，或者进入「调整」拖动四角。边缘太淡、相纸重叠、缺角和扫描阴影都可能影响自动识别。

朝向识别也可能不确定，尤其是风景、背影或很小的人脸。待检查提示是在邀请你确认结果，不代表照片已经损坏。

</details>

<details>
<summary><strong>为什么预览看着比较小？会影响导出清晰度吗？</strong></summary>

预览会缩小，方便电脑同时展示多张照片；最终裁剪从原扫描图计算，不是把屏幕上的预览图放大导出。

最终清晰度取决于扫描原图，旋转与透视校正会涉及必要的图像重采样。清楚的原扫描图，能给后续整理留下更多细节。

</details>

<details>
<summary><strong>导出之后是什么文件？可以发给朋友吗？</strong></summary>

照片以 PNG 保存，可以选择导出到文件夹或打成 ZIP。PNG 可以直接查看、用于排版或分享；ZIP 需要先解压，再取出里面的照片。

项目文件 `.polascan` 用于回到 InstaCrop 继续编辑，分享成品通常用导出的照片更方便。

</details>

<details>
<summary><strong>Mac 和手机能用吗？</strong></summary>

当前提供的是 Windows 10 / 11 的 64 位桌面便携版，没有 Mac、手机或小程序版本。

</details>

<details>
<summary><strong>需要付费、注册账号或者买 AI 额度吗？</strong></summary>

当前仓库公开提供源码与 Windows 发行包，裁剪版无需注册或购买 AI 额度。安装好窗口运行组件后，就可以在电脑上整理照片。

</details>

<details>
<summary><strong>🛠 给想看源码的人：运行、构建与验证</strong></summary>

普通使用者下载发行包即可，不需要执行下面这些命令。

源码运行需要 Python 3.10 或更新版本。Windows 中运行 `start.ps1` 会创建项目独立环境并启动工作台。

```powershell
./start.ps1
```

命令行批量处理与使用复核记录重新导出：

```powershell
python scanner.py "扫描图文件夹" --output outputs --trim 2
python scanner.py "扫描图.png" --review "outputs/扫描图_page1/manifest.json" --output outputs
```

安装开发依赖、测试与打包：

```powershell
python -m pip install -r requirements-desktop.txt
python -m unittest discover -s tests -v
python desktop.py --self-test outputs/self-test.json
./build.ps1
```

v1.0.3 拆分图片库、扫描裁剪和照片调整；素材分类、来源管理与导入入口相互对应，导出与批量参数只处理当前结果。照片导出仍只保留三类成图。发布时运行自动测试、界面回归检查与发行 EXE 功能自检。`build.ps1` 生成 Windows 便携 ZIP 与 SHA256 文件。仓库包含 GitHub Actions 测试与发行配置。

界面测试使用合成素材，不读取个人工作区：

```powershell
npm install --no-save playwright@1.62.1
node scripts/verify_ui_pages.cjs
```

本机默认使用 Microsoft Edge；CI 安装 Chromium 并设置 `UI_TEST_BROWSER=chromium`。`outputs/ui-pages/verification.json` 保存测试结果与检查项，截图保存在同一目录。

默认工作区为 `%LOCALAPPDATA%/PolaScanCrop/workspace`，环境变量 `POLASCAN_DATA_DIR` 可指定独立目录。项目中保留了 `.polascan` 文件格式，以方便保存静态照片编辑记录。

</details>
