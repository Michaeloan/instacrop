# InstaCrop 1.0.5 缺陷修复

本轮覆盖图片管理、导入、裁剪修复、任务退出、项目恢复和照片导出。

- 修复模块切换丢失来源、选择失败后不能重试、旧刷新结果覆盖新选择。
- 修复切换照片保留旧参数、笔刷草稿串图、加载过期页面、保存时迟到的角点吸附修改照片。
- 批量参数固定弹窗打开时的选择范围，避免后台新增照片被一起处理。
- 空选择和错误选择不再自动导出全部照片。
- 磁盘提交失败同时回滚内存修改与撤销记录，重试不产生虚假页面。
- 勾选状态参与页面版本检查，旧编辑不能覆盖新的选择。
- 导入和重开使用相同像素上限，已有大扫描项目可以正常恢复。
- 打开项目与任务提交互相保护；退出或入队失败不会留下假任务；取消时的状态读取不再异常。
- 长文件名使用短的内部临时名称，未被任务接管的上传文件会清理。
- 缩略图、放大镜和裁剪分析只读取需要的扫描内容，不额外读取完整原始文件。

新增的回归检查使用合成素材和临时工作区，包含磁盘故障注入、异步响应逆序、选择与导出范围、任务并发和真实浏览器操作。GitHub Actions 同时运行自动测试、界面回归、自检和 Windows 打包。

该版本保持照片管理与裁剪修复范围。
